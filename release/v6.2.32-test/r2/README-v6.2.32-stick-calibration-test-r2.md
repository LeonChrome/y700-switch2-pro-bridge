# V6.2.32 Test r2 摇杆双校准测试版

## 更新重点
- 每个 Pro2 Slot 增加“零位 2 秒”和“完整行程 8 秒”两项摇杆校准。
- 校准数据按真实 Pro2 的 BLE 地址独立保存，四个手柄槽互不混用。
- 零位校准分别记录 `LX/LY/RX/RY` 四轴中心。
- 完整行程校准分别记录四轴八方向端点，并保留 3% 外圈余量，使存在个体行程差异的摇杆也能稳定输出到逻辑极限。
- 未校准设备继续使用中心自动学习与固定 `±1600` 回退，不强制改变原有手感。

## r2 修复
- 修复完整行程采样启动后，被自动重连守护每 750ms 重复加载已保存零位配置并中止的问题。
- 相同配置的重复应用现在是幂等操作，校准采样期间不会被后台配置刷新覆盖。
- 校准期间显示秒级倒计时。
- 校准结束后明确提示成功、行程不完整、有效样本不足或连接中断。
- 相同校准配置不再重复刷入运行日志。

## 操作方法
1. 启动一个手柄模式并连接真实 Pro2。
2. 点击对应 Slot 的“零位 2 秒”，完全松开两个摇杆并保持静止。
3. 零位成功后点击“完整行程 8 秒”。
4. 在倒计时内让左右摇杆分别贴着外圈完整转动至少三圈，确保上、下、左、右都推到底。
5. 完成后配置会立即应用，并在以后连接同一 BLE 地址时自动加载。

## 安全边界
- 零位采样检测到移动时不会保存。
- 完整行程缺少任一方向时不会覆盖旧配置。
- 采样期间手柄离线或连接对象变化时不会保存。
- 本版本没有修改按键、陀螺仪、震动、VIIPER/USBIP、四模式身份或 BLE 输入节奏。
