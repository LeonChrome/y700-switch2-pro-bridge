# V6.2.29 真实 BLE 源节奏版

## 更新重点
- 默认输出节奏改为跟随真实 Pro2 BLE 通知。Win11 实际收到 60-80Hz 就输出 60-80Hz，不再把虚拟端强行固定到 250Hz。
- C# 输入端采用 latest-state：Windows 将多条 BLE 通知批量交付时，只发送最新状态，并记录被合并帧数；不会把旧摇杆轨迹压缩到后续 USB 周期重播。
- 内嵌 VIIPER 的 Pro2 USB 端点同步采用 source-paced latest-state。待处理状态只保留一份，主机来不及消费时自然合并，不积压 FIFO。
- 修复无线 Pro2 模式猛推右摇杆时，Steam 桌面鼠标或游戏地图出现与推动速度成比例的“瞬移”问题。修复不改变摇杆量程、死区、滤波或曲线。
- 输入源超过 100ms 未更新时立即发送一次中立状态，之后等待真实新输入；避免旧方向卡住，也不制造高频中立帧。
- 固定 66Hz / 125Hz / 250Hz 保留为诊断档位，旧版保存的固定频率设置会自动迁移到真实 BLE 源节奏。
- VIIPER 与 USBIP 安装器继续内嵌；注册表路径识别、待重启诊断、有序拔出和 Steam 缓存收尾保持不变。

## 保留能力
- 新和联胜 / PS5：DualSense 身份、HD 音频震动与普通震动调度、PS5 IMU 优化。
- PS5 Edge：Edge 身份与背键支持。
- Pro2 / Nintendo：Steam 原生 Pro Controller 路线。
- Xbox / XInput：广泛兼容路线与背键映射。
- 四个正式模式均支持 1-4 个独立 Pro2 BLE Slot。
- 陀螺仪、加速度、震动调度和手柄身份映射本轮未改。

## 首次使用提醒
- 如果安装 USBIP 后仍提示驱动未就绪，通常需要重启 Windows。
- 蓝牙扫描不到手柄时，请确认手柄已唤醒、未被 Switch/手机/ESP32/旧 EXE 占用，并确认 USB 蓝牙接收器支持 BLE Central。
- 日常使用请保持“跟随真实 Pro2 BLE（推荐）”；固定频率档仅用于排查特定电脑的调度问题。
