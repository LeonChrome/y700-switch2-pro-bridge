# V5.9.16 ESP 首次运行向导版

## 更新内容

- 新增首次运行向导，并可从主界面随时重新打开。
- 使用动态双 USB 示意图区分 CH343/COM 控制线和原生 USB/OTG 数据线。
- 引导检测 ESP32-S3 控制板，避免把 Windows 蓝牙虚拟串口误当成刷写口。
- 支持 PS5、PS5 Edge、Pro2 / Nintendo、Xbox / XInput 四个正式模式的一键刷写。
- 刷写失败时分类提示 CH343 驱动不兼容、ESP32-S3 未进入下载模式、串口不可用或刷写器失败。
- 刷写完成后按目标 VID/PID 验证 Windows 手柄身份。
- 自动配对必须确认真实 Pro2 输入新鲜才判定成功；超时后提供 BLE 扫描、目标选择和手动连接兜底。
- 配对完成后提示可以拔掉 CH343/COM 控制线，只保留 USB/OTG 数据线。

## 保留能力

- PS5 / PS5 Edge 的 IMU 与 HD/普通震动调度保持 V5.9.15 成果。
- Pro2 / Nintendo 与 Xbox / XInput 固件路径保持不变。
- 内置 esptool、CH343 驱动诊断/修复、固件清理及日志工具。

## 校验

- Debug / Release 构建：0 警告、0 错误。
- 内置 6 个 profile、18 个固件资产及辅助工具自检通过。
- BLE 状态解析、下载模式识别和 CH343 驱动风险测试通过。
