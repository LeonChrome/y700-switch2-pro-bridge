# V5.9.17 ESP 真实 BLE 源节奏版

## 本次修复
- 新和联胜 / PS5、PS5 Edge、Pro2 / Nintendo、Xbox / XInput 四套固件的实时输入均改为跟随真实 Pro2 BLE 通知节奏。
- BLE 每产生一个新 `updates` 状态，固件最多发布一次最新 HID 状态；主机忙碌时中间状态自然合并，不在之后高速补播。
- 移除实时链路固定 250Hz 重复发送。ESP 实际收到约 133Hz 就按约 133Hz 输出，不伪造更高的有效采样率。
- 输入断开或超过时限未更新时，立即发送一次中立状态，之后以 20Hz 低频保活，避免摇杆方向卡住。
- 固件的手动按键测试仍可使用配置频率；该频率不再控制真实 BLE 输入。
- 默认诊断频率从 250Hz 调整为 133Hz，减少状态页造成的误解。

## 保持不变
- PS5 / Edge 身份、PS5 IMU 参数、HD 音频震动与普通震动严格调度不变。
- Pro2 / Nintendo 与 Xbox / XInput 的按键、摇杆量程、背键和震动映射不变。
- 双 USB 首次运行向导、刷写失败分类、USB 身份验证、自动配对与手动 BLE 扫描保留。

## 使用建议
- 刷入目标模式后，真实回报率请以日志中的 BLE 输入统计和 HID 实际发送统计为准。
- 不需要为了追求数字手动设置 250Hz；BLE 源没有新样本时，重复发送不会增加真实信息量。
