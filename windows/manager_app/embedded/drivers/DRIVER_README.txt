WCH CH343P / CH340 driver helper

This folder is reserved for optional local driver packages.

Recommended official pages:
CH343CDC.EXE
https://www.wch-ic.com/downloads/CH343CDC_EXE.html

CH341SER.EXE
https://www.wch-ic.com/downloads/CH341SER.EXE.html?type=en

The manager opens these official links from the Driver Assistant. If a redistributable driver installer is added to this folder in a future package, the manager can expose it as a local install option.
