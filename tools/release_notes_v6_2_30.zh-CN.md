# V6.2.30 按键边沿热修版

## 修复重点
- 修复 V6.2.29 在 Pro2 无线模式下偶发“按一次变双击”或持续按键被重复触发的问题。
- 根因是 Windows BLE 通知短暂间隙超过 100ms 时，V6.2.29 会主动写入一帧全松开；如果实体按键仍按住，下一帧真实输入会再次变成按下，从而制造并不存在的松开/按下边沿。
- V6.2.30 在 BLE 输入源仍处于连接运行状态时保持最后控制状态，不再因通知抖动注入中立帧。
- 只有 BLE 输入源明确停止或断开时，才发送一次全松开，既避免卡键，也不会重复制造按键边沿。
- 新虚拟设备会优先采用输入源当前最新状态，避免模式切换瞬间插入一次无意义的松开帧。

## 节奏策略
- 保持 V6.2.29 的真实 BLE 源节奏与 latest-state 策略：Win11 实际收到 60-80Hz 就按真实新状态输出，不强制补到 250Hz。
- 待处理输入仍只保留最新状态，不重播积压轨迹，因此不恢复右摇杆猛推瞬移问题。
- 本轮没有增加按键防抖、延迟窗口或滤波，不会吞掉真实快速点击。

## 保持不变
- 新和联胜 / PS5、PS5 Edge、Pro2 / Nintendo、Xbox / XInput 四个正式模式。
- 四个模式的 1-4 个独立 Pro2 BLE Slot。
- 摇杆量程、死区、曲线、陀螺仪、加速度、HD 震动与普通震动调度。
- 内嵌 VIIPER / USBIP、注册表路径识别、驱动待重启诊断与有序拔出逻辑。

## 首次使用提醒
- 如果安装 USBIP 后仍提示驱动未就绪，通常需要重启 Windows。
- 蓝牙扫描不到手柄时，请确认手柄已唤醒、未被 Switch、手机、ESP32 或旧版 EXE 占用，并确认 USB 蓝牙接收器支持 BLE Central。
- 日常使用请保持“跟随真实 Pro2 BLE（推荐）”；固定频率档仅用于诊断。
