# V5.2 Experimental ns2pro VIIPER HD Rumble Forwarding

## 中文

V5.2 是实验版本，目标是把 VIIPER 虚拟 `ns2pro` 的 HD rumble payload 捕获出来，再通过 ESP32-S3 firmware/control 的 raw02 命令转发到真实 Switch 2 Pro Controller。

默认模式不变：

```text
output_mode=pro2
ns2pro_viiper=Experimental
default_enabled=false
```

## Highlights

- 新增 VIIPER ns2pro 实验路线。
- 新增 raw02 固件命令：`rumble raw02 <hex>`。
- 新增 Pro2 HD rumble forwarding probe。
- 支持从 VIIPER ns2pro 捕获 `LeftRumble[16] / RightRumble[16]`。
- 支持 raw02 转发到真实 Pro2。
- 真实 Pro2 按键、gyro、震动链路已验证。
- 默认模式仍然是 `pro2`，不自动启用 `ns2pro_viiper`。

## Requirements

- ESP32-S3 bridge。
- 已刷入 raw02 firmware。
- usbip-win2。
- VIIPER。
- Windows。
- 真实 Pro2 已通过 BLE 连接。
- CH343P 串口控制口可用。

## What Works

```text
Pro2 input=true
gyro=true
raw02_low=true
raw02_medium=true
raw02_captured_viiper=true
VIIPER_16_16_capture=true
forwarding_to_real_Pro2=true
physical_vibration=true
rumble_writes=49
rumble_errors=0
ble_disconnect=false
```

## Limitations

- Steam/SDL ordinary rumble 不等于 ns2pro HD `0x02`。
- 游戏是否主动发送 Pro2 HD rumble 取决于游戏、Steam Input 和输入栈。
- `ns2pro_viiper` 仍为 Experimental，不默认启用。
- V5.2 不承诺所有游戏原生触发 Pro2 HD rumble。
- DualSense / PS5 haptic 不在 V5.2 范围内。
- 语音、耳机、麦克风和完整 HD Rumble 2 音频复刻不在 V5.2 范围内。

## Safety

- 不要循环高强度 rumble。
- captured VIIPER 测试默认使用 `-MaxPackets 1`。
- raw02 真实发送必须显式传入 `-Send` 或 `-SendToRealPro2`。
- 先跑 `low`，再跑 `medium`，最后再跑 captured VIIPER payload。
- 如出现异常长震动或 BLE 断连，立即执行 `rumble stop` 并停止测试。

Stop command:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\esp32s3\send_command.ps1 -Port COM12 -Command "rumble stop"
```

## Validation Commands

Check VIIPER environment:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\check_viiper_env.ps1
```

Run the VIIPER ns2pro HID rumble probe:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\experiments\viiper_ns2pro_hid_rumble_probe\run_viiper_ns2pro_hid_rumble_probe.ps1
```

Send low raw02 to the real Pro2:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\send_pro2_raw02.ps1 -Preset low -Send -Port COM12
```

Send medium raw02 to the real Pro2:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\send_pro2_raw02.ps1 -Preset medium -Send -Port COM12
```

Capture VIIPER 16+16 and send to the real Pro2:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\experiments\viiper_ns2pro_to_real_pro2_rumble_probe\run_ns2pro_to_real_pro2_rumble_probe.ps1 -CaptureViiper -SendToRealPro2 -Port COM12 -MaxPackets 1 -MinIntervalMs 100 -TimeoutSeconds 35
```

## English

V5.2 is an experimental release that captures VIIPER virtual `ns2pro` HD rumble payloads and forwards them to the real Switch 2 Pro Controller through the ESP32-S3 firmware/control raw02 command.

Default mode is unchanged:

```text
output_mode=pro2
ns2pro_viiper=Experimental
default_enabled=false
```

Highlights:

- Adds the VIIPER ns2pro experimental route.
- Adds the firmware command `rumble raw02 <hex>`.
- Adds the Pro2 HD rumble forwarding probe.
- Captures `LeftRumble[16] / RightRumble[16]` from VIIPER ns2pro.
- Forwards raw02 payloads to the real Pro2.
- Verifies real Pro2 input, gyro, and rumble chain.
- Keeps `pro2` as the default mode.

Limitations:

- Steam/SDL ordinary rumble is not ns2pro HD `0x02`.
- Native Pro2 HD rumble depends on the game, Steam Input, and input stack.
- `ns2pro_viiper` remains Experimental and is not enabled by default.
- V5.2 does not claim all games can natively trigger Pro2 HD rumble.
- DualSense / PS5 haptic support is not part of V5.2.
