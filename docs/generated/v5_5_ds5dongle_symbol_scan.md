## Machine Summary

- USB identity is implemented in `src/usb_descriptors.cpp` with Sony VID `0x054C` and runtime DS5/Edge PID selection.
- The USB shape combines HID with bidirectional audio streaming; optional CDC is a build option.
- PC audio enters through TinyUSB audio callbacks. Four 48 kHz, 16-bit OUT channels are split into speaker L/R and haptic L/R.
- Haptic channels are resampled and packed into Bluetooth output report `0x36` for a real DualSense.
- USB HID OUT report `0x02` is decoded by `state_update` and then forwarded through `bt_write`.
- Input report `0x01` and several feature reports are sourced from the real DualSense Bluetooth backend.
- The V5.5 port should retain the PC-facing USB contract while replacing the real-DualSense backend with Pro2 BLE input and raw02 output backends.
